## 🎓 Thesis Title
**“Design of Optimized Path Generation for Physical Guidance Driven Collaborative Robot Using Metaheuristic Algorithm”**

---

## 🧠 Project Overview
The project focuses on developing an **optimized path generation system** for a **collaborative robot (cobot)** using a **metaheuristic algorithm**, specifically the **Genetic Algorithm (GA)**.

In simpler terms, it enables users to **teach a robotic arm tasks through physical guidance**—no advanced programming knowledge required. Once trained, the cobot can accurately **replicate repetitive tasks** on its own.

## 💻 Web Application
To complement the system, Kinectica developed a **web-based control interface** for the cobot.  
The application allows users to:
- Switch between different operating modes:  
  - **Idle** – standby mode  
  - **Teaching** – record new guided movements  
  - **Demonstration** – replay stored actions  
- **Select and execute saved tasks**  
- Manage and monitor the cobot’s operation in real time
